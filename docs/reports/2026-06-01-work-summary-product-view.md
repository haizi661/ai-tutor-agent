# 5/25 → 现在:产品视角工作汇报(通俗版)

更新时间:2026-06-01
受众:老板 / 同事 / 不看代码的人
基线:5/25 那个能用的版本 vs 现在线上的版本

> 一句话:**5/25 那时只有一条"人工智能知识图谱"的轻量教学,自动控制原理这条线还没跑通完整闭环。现在两门课都能跑,前端多了 8 块可看见的工作。**

---

## 1. 选方向(自动控制原理 / 人工智能)

- **改了什么**:5/25 那时候只能走"人工智能知识图谱"独立子服务。现在统一了方向选择,可以选择"自动控制原理"或"人工智能",会话状态会跟着方向走。
- **作用**:一个平台能教两门课,以后能加第三门(数据/网络通识等)。
- **前端位置**:首次进入聊天会弹"课程选择卡",**顶部 Header 始终显示当前课程名**;点 Header 也能换方向。

## 2. 学前测评 + 学习画像

- **改了什么**:5/25 没测评,一上来就讲。现在新会话先做 5-10 道学前测评,系统生成一份"学生雷达图"(6 个维度:基础概念 / 数学基础 / 应用能力 / 边界辨析 / 公式熟练 / 综合判断)。
- **作用**:系统知道学生哪里强哪里弱,讲解针对性补薄弱维度,不出"对牛弹琴"的题。
- **前端位置**:**主聊天区出答题卡** → 提交后出一张**雷达图卡片**(6 维评分),学生侧栏也能看到画像。

## 3. 多步学习路径(分阶段,不是平铺)

- **改了什么**:5/25 AI 那条是平铺节点列表(一条直线),现在自动控制原理是**分阶段的多步路径**(基础 → 时域 → 频域 → 校正 → 离散 → 状态空间,每步 4-8 个节点)。系统按学生学情决定从哪步开始、每步包含几个节点。
- **作用**:学生能看清"整个课程拆几大步,我现在在哪步、这步里有几个知识点、还有几个没学"。
- **前端位置**:**右侧独立学习路径面板**(可折叠收起),主聊天内也有学习路径卡。每个节点有 mastered / in_progress / upcoming / goal 状态色。

## 4. 知识点个性化讲解

- **改了什么**:5/25 LLM 单一通道讲,所有学生听到的版本一样。现在按**学生水平(5 档)+ 错因(5 类)切教学策略**:基础差听到类比版,基础好听到苏格拉底挑战版;概念混淆用引导式,计算错误用逐步拆解。
- **作用**:同一个知识点,不同学生听到的版本不一样;卡点能精确识别和切换。
- **前端位置**:**主聊天区讲解气泡**(讲解正文),开启"教学推理透明"模式时,讲解上方会显示"为什么这样讲"(用了什么策略、检测到学生什么状态)。

## 5. 学后客观小测(打分 + 过关判定)

- **改了什么**:5/25 节点讲完就推进,没客观小测。现在每个节点讲完,系统**自动出 10 道 4 选 1 题**(题库优先 → LLM 出题 → 模板兜底,三级流水线),学生作答,系统打分并判定过没过。
- **作用**:有明确"过/没过"门槛(80 分 + 必会目标 70% 正确率),没过就强制进补救;有量化掌握度,而不是"感觉懂了"。
- **前端位置**:**主聊天区答题卡**(题目 + 4 选项,4 行稳定全宽),提交后出**批改卡**(对错号、正确答案、解析、错误选项分析、判断依据、下一步建议)。

## 6. 错题补救(变式 / 复习 / 收束,带硬上限)

- **改了什么**:5/25 错题就显示一遍,没补救。现在小测没过,系统**给 3 选项决策卡**:继续做变式训练 / 复习本节点 / 加入错题本,且带**硬上限**——同一节点最多 2 轮变式,同一目标连续错 2 次自动停,额外补救题不超过 10 道。
- **作用**:不让错题溜走,但也防止"题海战术"压垮学生。
- **前端位置**:**主聊天区决策卡**(分数档不同选项不同——60-79 给"继续变式/复习/稍后",60 以下给"复习/稍后/仍然变式")。变式题答题卡样式同客观小测。

## 7. 错题本 + 临时提问(独立 UI)

- **改了什么**:5/25 完全没有这两个。现在有两个独立 UI:
  - **错题本**:所有错过且未掌握的题集中管理,按节点分组,可"标记已掌握/取消掌握"
  - **临时问题侧弹窗**:学生突然卡一个具体问题(可上传图片),三模式 quick(快答) / deep(深度) / vision(看图)
- **作用**:错题本让复习有抓手,临时问题不打断主线节奏(可关闭返回)。
- **前端位置**:
  - **错题本**:从聊天区或顶部入口进入,独立列表,默认"待复习/未掌握"过滤
  - **临时问题**:**主聊天区右侧可滑入的 modal**,不影响左边对话流

## 8. 会话恢复 + 状态不丢(作业 / 节点 / 主题)

- **改了什么**:5/25 关了页面就重头开始,作业 / 当前节点 / 主题都可能丢。现在有**黑名单模式会话恢复**——新会话 / 刷新 / 历史恢复,自动识别"还有未完成作业的会话",并续上当前节点、当前主题、待办作业。
- **作用**:作业分配了做到一半不会丢;学生隔天回来能直接接着昨天的进度。
- **前端位置**:**左侧历史对话列表**(每条有状态标签:进行中 / 已完成 / 作业待批 / 暂停复习),点任意一条恢复,自动滚动到当前未答的卡,Header 同步显示当前节点。

## 一句话总览(汇报开场用)

> 5/25 那时只有一条"人工智能知识图谱"的轻量教学,自动控制原理还没跑通完整闭环。从 5/25 到现在,主流程加 1 个新节点、5 个节点大改、12 个状态字段、30 道题、2 个独立 UI(错题本、临时问题)、1 套学习方向切换。前端用户能直接看到的成果是 8 块:**选方向、学前测评、多步路径、个性化讲解、客观小测、错题补救、错题本+临时提问、会话恢复**——核心是"教学过程可量化、有补救、会保留状态"。

## 老板 1 分钟口播版(更短)

> 5/25 那个版本,我们只有 AI 知识图谱一条线。现在**自动控制原理也跑通了完整教学闭环**:学生进来先选课,做 5-10 道测评看自己强弱,系统按"基础→时域→频域→校正→离散→状态空间"分步推进,每讲一个知识点就出 10 道题打分,80 分以下进错题补救(最多 2 轮变式),错题可加错题本反复复习,学生临时卡住可弹窗提问,作业做到一半关掉再回来不丢。同时**人工智能这条线仍跑独立子服务**,通过"选方向"切换,**两个方向共享同一份学生状态**。后端 28 个 LangGraph 节点 + 30+ 测试 + 4 份设计文档已经齐了,**下一步是学习路径 v2 + 教学能力优化**(在 working tree 里,42 处未提交)。
