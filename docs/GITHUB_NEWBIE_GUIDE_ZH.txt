ai-tutor-agent 新人 GitHub 操作指南

0. 前提（私有仓库）
1) 你必须先被仓库管理员邀请并接受邀请。
2) 确认你能打开仓库页面：
   https://github.com/haizi661/ai-tutor-agent

1. 第一次拉取代码
git clone https://github.com/haizi661/ai-tutor-agent.git
cd ai-tutor-agent
git branch -vv
git remote -v

如果没有 main -> origin/main 的跟踪关系，执行：
git branch --set-upstream-to=origin/main main

2. 配置本机 Git 身份（只需一次）
git config --global user.name "你的名字"
git config --global user.email "你的GitHub邮箱"

3. 项目启动（本项目专用）
pip install -e .
# 或 pip install -r requirements.txt

cp .env.example .env
# 在 .env 中选择一个你实际会使用的厂商 key 填入，例如：
# GEMINI_API_KEY=...
# QWEN_API_KEY=...
# DEEPSEEK_API_KEY=...
# OPENAI_API_KEY=...
# MINIMAX_API_KEY=...
# GLM_API_KEY=...
# 如果你的网络不能直连模型 API 或 HuggingFace，再按 docs/RUNBOOK_ZH.md 配置：
# HTTP_PROXY=http://127.0.0.1:7897
# HTTPS_PROXY=http://127.0.0.1:7897

PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q
python main.py

4. 日常开发（推荐流程：功能分支 + PR）
git checkout main
git pull --rebase origin main
git checkout -b feat/你的功能名

# 开发代码后
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q
git add .
git commit -m "feat: 你的改动说明"
git push -u origin feat/你的功能名

然后在 GitHub 发 PR 合并到 main。

5. 不要提交这些文件
- .env
- data/*.db
- data/*.db-wal
- data/*.db-shm
- data/knowledge/*
- *.log
- __pycache__/

6. 提交前快速自检
git status -sb
git diff
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 python -m pytest -q
